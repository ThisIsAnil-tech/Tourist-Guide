# Tourist Safety Mobile App

Flutter mobile app for the Smart Tourist Safety and Incident Response System.
Detects distress automatically, sends SOS alerts via internet, SMS, or nearby-device
mesh relay, and keeps tourist identity locked until a verified responder needs it.

## Tech Stack

- Flutter (iOS + Android)
- Provider (state management)
- go_router (navigation)
- Dio (networking)
- TensorFlow Lite (on-device audio detection)
- Google Maps Flutter (risk zone map)
- Nearby Connections (offline mesh relay)

# Tourist Safety Admin Dashboard

React admin dashboard for the Smart Tourist Safety and Incident Response System.
Monitors live SOS events, model test results, risk zones, tourists, and responders.

## Tech Stack

- React + Vite
- React Router
- Axios
- Recharts (charts)
- React-Leaflet (maps)
- Single CSS file, no UI framework
